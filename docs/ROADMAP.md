# Roadmap

1. Broaden public Ref2VA input coverage and clean-environment compatibility beyond the pinned H3 source.
2. Package reproducible Linux SM120 binaries after compiler/driver matrix qualification.
3. Register the node package and publish gallery workflows once publisher metadata is available.
4. Benchmark sustained service completion throughput with the bounded export queue; measure CPU and RAM budgets.
5. Evaluate newer CUTLASS/Kitchen kernels with per-stage and full-request comparisons before changing defaults.
6. Port useful exact VAE candidates independently; keep sparse/cache/low-bit experiments explicitly separate.

Current implementation and limitations: [release scope](RELEASE-SCOPE.md).
